# Инструкция по установке и запуску.

## 1. Клонирование репозитория  

```bash
git clone https://github.com/medicsera/typescript.git
```
```bash
cd typescript
```
```bash
git checkout Introduction-to-TypeScript
```
```bash
yarn add node-ts
```

## 2. Запуск заданий

```bash
yarn run taskN
```
Где вместо N указывается номер задания (от 1 до 9)
